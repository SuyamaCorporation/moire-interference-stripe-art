# モアレ干渉縞アート描画

2種の周期縞を重ねたとき現れるモアレ干渉縞をブラウザ上でリアルタイム描画。縞の間隔・角度・変位スライダーで模様をコントロールし、PNG出力が可能。

## 機能
- 2レイヤー縞パターンを差分ブレンドで重ねてモアレを生成
- 縞の間隔1・2スライダー（5〜50px）
- 角度1・2スライダー（0〜180°）で縞の向きを個別調整
- 変位スライダーでフェーズオフセットを調整
- パターン種別選択：正弦波 / 矩形波 / 同心円
- アニメーショントグルで角度2を自動回転させてモアレをアニメーション
- スライダー変更ごとにリアルタイム再描画（ImageDataで高速処理）
- PNG保存ボタンで画像出力
